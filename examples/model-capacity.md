# Example: Recognize a Representation's Hard Limit

A condensed English illustration of a two-choice source case, not the complete
evaluation item. The complete item includes the frozen project and longer plans.

## Research state

The current scientific ML controller has 4,780 parameters. A criterion of 400
distinct occupied decisions per parameter requires 1,912,000 decisions, but
exhaustive analysis puts the current topology's upper bound at 8,748. The agent
is nevertheless planning pretraining checkpoints and paired PDE search runs.
An alternative topology has already been authorized.

## Plans

**A.** Switch to the authorized feasible topology first. Rebuild matched control
and treatment, data bindings, labels and normalizers. Meet the data sufficiency,
learnability and runner gates before training and transfer evaluation.

**B.** Proceed with pretraining the current topology on the available roster,
then run the paired PDE search experiments at the planned full step budget.

## Reference: A

Adding data cannot change the topology's hard capacity bound. The existing
configuration cannot meet the stated criterion. The source reference switches
to a 143-parameter topology with a raw capacity of 98,415 occupied decisions,
then requires data acquisition and validation gates before training. It also
rebuilds both arms and excludes incompatible old checkpoints.
